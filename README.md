# QrzSpace — releases

Instaladores do **QrzSpace**, a central de trabalho desktop (Windows).

**[⬇ Baixar a versão mais recente](https://github.com/PQueirozDev/QrzSpace-releases/releases/latest)** → `QrzSpace-Setup-<versão>.exe`

- Depois de instalado, o QrzSpace se atualiza sozinho a partir deste repositório.
- Cada download é conferido pelo SHA-512 publicado no `latest.yml` da release; um arquivo adulterado é descartado.
- Este repositório contém **apenas os instaladores**. O código-fonte é privado.
- O instalador ainda não tem assinatura de código: na primeira execução o Windows SmartScreen pode avisar ("Mais informações" → "Executar assim mesmo").

As novidades de cada versão aparecem nas releases e na aba **Novidades** do app.
